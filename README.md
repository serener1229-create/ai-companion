# Niko Web App

This is the iPhone-friendly Progressive Web App version of Niko.

## Important
The frontend is ready, but the AI requires the Niko backend from the previous project.

Before using AI chat, set `BACKEND_URL` in `app.js` to the address where your backend is hosted.

Do not put an OpenAI API key in this frontend.

## iPhone
Host this folder on HTTPS, open it in Safari, then use:
Share → Add to Home Screen.

The browser/PWA can use speech recognition and speech synthesis where supported.

## Current features
- Niko home screen
- General chat UI
- Language learning shortcuts
- Local memory
- Medical information screen
- Emergency screen
- Voice input/output where browser support allows
- Installable PWA structure
